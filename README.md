# PROSHIKA HRMS – User Manual

A web-based user manual for the **PROSHIKA Human Resource Management System (HRMS)**. This project provides documentation and guidance to help users understand and navigate the system's modules and features.

## Project Overview

The PROSHIKA HRMS User Manual is designed to provide users with organized, accessible documentation for different functionalities of the HRMS application.

It serves as a reference guide for understanding system operations, navigating modules, and following the relevant procedures.

## Features

- Organized user documentation
- Module-wise information and guidance
- Responsive web interface
- Interactive navigation
- Reusable HTML partials
- Custom CSS styling and JavaScript functionality

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive Web Design

## Getting Started

### Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/rohanrashid97/proshika-hrms-user-manual.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser.

For the best experience, use a local development server if the project uses JavaScript-based loading of HTML partials.
